EDUSYNC PIPELINE: ZERO-DATA-LOSS OFFLINE LEARNING
How work flows reliably from a student's phone to the teacher's gradebook
Core Technologies (Simplified)
  • React 18 & Vite (Screen): The buttons, forms, and pages the student touches. Updates instantly with 0ms delay so it never freezes.
  • IndexedDB (Phone Storage): A tamper-proof storage box right inside the browser. Survives phone restarts and dead batteries.
  • Cloudflare D1 (Global Server): Fast cloud database running in 300+ cities globally. Absorbs retry clicks so you are never double-submitted.
  • Yjs CRDTs (Co-Editing): Math formula that blends edits from multiple offline students without losing a single letter.
The 5-Step Data Synchronization Pipeline
  • ➔ 1. WRITE (0ms Instant Local): Student types an essay. React updates the screen instantly without asking the internet.
  • ➔ 2. LOG (Local Disk Commit): Every keystroke is permanently written to an IndexedDB operation log on physical storage.
  • ➔ 3. STATE (Truthful Badge): The app shows 'Offline · 2 changes saved'. Students feel completely safe continuing.
  • ➔ 4. DRAIN (Jittered Queue): When Wi-Fi returns, the phone gently flushes the queue without overwhelming school routers.
  • ➔ 5. RECONCILE (Cloudflare D1): The server receives the work, verifies the unique receipt ID, and confirms 'All synchronized'.

  • Hybrid Logical Clocks: Merges physical time with sequence counts to eliminate drift.
