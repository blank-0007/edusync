Student Action
Student writes essay or clicks Submit Assignment. React updates screen instantly.

STAGE 2
🔒
Local Op-Log
Keystroke writes synchronously to IndexedDB on phone disk before touching the wire.
💾 Survives Browser Kill & Dead Battery
STAGE 3
🏷️
State & Receipt
Mints client-side ULID token; displays confirmed offline receipt and queued count.
🧾 Instant Official Receipt with 0 Wi-Fi
STAGE 4
📡
Jittered Drain
Phone detects Wi-Fi; flushes queue with randomized backoff so routers don't crash.
🎲 Prevents 50-Student Network Crashes
STAGE 5
☁️
D1 Reconcile
Cloudflare D1 verifies ULID, absorbs retries, checks 409 diffs, and marks "All Synced".
✅ 100% Convergence · 0 Duplicates
💡
Core Invariant: "The device is the source of truth, the network is an optimization." Even if connection drops permanently, every word is safely preserved on the device and can be audited.
