±25% jitter stops a lecture hall of 60 devices from stampeding the gateway the moment wifi returns. The 30 s cap means a flaky 2G link is never punished with a long sleep — and n resets on the first success.
The invariant
Never drops un-acked ops
The queue is the contract between the student and the platform. It is emptied only one way: an ack.
✓
Durable in SQLite-WASM / OPFS — survives tab close, crash and reboot.
✓
Ack is the only removal path; rejected ops are surfaced, never deleted.
✓
Overflow is handled by back-pressure (pause syncing), not by dropping.
✓
No timer or eviction policy can expire an op — only an ack can.
✓
Only superseded drafts may be coalesced — never submitted work.
Kill the network mid-batch, kill the app, reopen it: the same 12 ops are still queued and the demo still converges.
