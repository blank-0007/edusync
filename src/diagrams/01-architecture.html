The reconciliation spine
One path, every write
Not a cache layer bolted onto CRUD — this ordering is what makes the platform correct under partition.
01
intent
user acts · UI never waits on a network round trip
02
local durable op
opId (ULID) + HLC + payload + device signature, committed to SQLite/OPFS & the op log
03
UI reflects instantly
optimistic render from local state · no spinner between a student and their own words
04
queue
coalesced, bounded, oldest-first · superseded drafts dropped — never submitted work
05
batched push
≤ 200 ops / 512 KB · HTTPS + WSS · resumable across app restarts
06
dedupe · order · validate
UNIQUE(op_id) wins races · HLC then deviceId · zod rejects malformed payloads
07
ack
applied / duplicate / rejected + serverRev · duplicate is safe to retry blindly
08
delta pull
Yjs state vectors + per-table cursor → kilobytes after 3 days offline, not gigabytes
09
merge
CRDT text · per-field HLC · domain policy · freeze & escalate — see the merge ladder
10
converge
byte-equal state hash across devices & server, asserted by property tests
11
audit
hash-chained events · every reconciliation decision recorded with actor + inputs
